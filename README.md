# Device API

API for device management, built with Java 21, Spring Boot, and PostgreSQL.

## Features

- Create, read, update, and delete devices
- Filter by brand and state
- Custom business exceptions

## Technologies

- Java 21
- Spring Boot
- Maven
- PostgreSQL (Bitnami)
- Docker / Docker Compose
